# C# Implementation

Visual Studio solution with clean protocol/UI separation.

## Open in Visual Studio

Open `GHL_Simulator_Deadboy.slnx` in Visual Studio 2022+.

## Structure

- `GHLProtocol.cs` - Protocol logic (connect, build packet, checksum, send/receive)
- `Program.cs` - WinForms GUI

## Publish

Right-click project > Publish > Folder Profile to create a standalone .exe.
